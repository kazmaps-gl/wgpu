# Архив wgpu

Незакоммиченные состояния worktree, собранные в одну ссылку — тег `archive`. Коммит тега пустой по коду: в нём только этот файл, а каждая линия — его родитель, так что `archive^N` — линия N. Пока тег существует, все коммиты линий доступны и не удаляются сборкой мусора.

## Как достать линию

```sh
git fetch origin tag archive --no-tags
git switch -c <имя> archive^N^1 && git stash apply --index archive^N
```
